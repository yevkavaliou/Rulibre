# Подготовка книги для ридера

Проблема №11, 11 октября 2026 года.

## Приоритеты и настройка

`plan_preparation(files, device, options, backends)` строит план по снимку
`BookFile` и возможностям конвертеров из этапа №8. План не запускает процессы
и не меняет файлы: `Ready`, `Convert` или `ViaEpub`.

| Устройство / режим | Готовые файлы | Если подходящего файла нет |
| --- | --- | --- |
| Kobo, `Compatible` (по умолчанию) | KEPUB, затем EPUB | Конвертация в EPUB |
| Kobo, `PreferKepub` | Готовый KEPUB | Прямой маршрут в KEPUB; затем маршрут через EPUB; затем fallback к готовому EPUB или конвертации в EPUB |
| Kindle | AZW3, затем MOBI | Конвертация в AZW3 |

Для одинакового формата выбирается минимальный нативный путь. Регистр расширений
не влияет на распознавание: `BOOK.KEPUB.EPUB` — KEPUB, `BOOK.EPUB` — EPUB.
KEPUB никогда не используется как обычный EPUB-источник. Если в библиотеке есть
только KEPUB, для Kindle маршрут отсутствует в принятой политике конвертации.

`PreparationOptions { kobo: KoboPreparation::PreferKepub }` — явная опция ядра.
Она передаётся в `prepare_file` или `DeviceState::send_book_with_options`.
Обычный `send_book` сохраняет сигнатуру и использует `Compatible`; существующие
TUI/Tauri получают новое поведение без изменения вызовов. Нового элемента UI
или поля сохраняемой конфигурации этот этап не добавляет.

Предпочтение KEPUB использует `kepubify` для EPUB либо `ebook-convert`
с подтверждённой возможностью вывода KEPUB. Если исходного EPUB нет, а Calibre
не имеет KEPUB-плагина, но `kepubify` доступен, план содержит два шага:
исходный формат → EPUB через Calibre → KEPUB через kepubify. Оба инструмента
выбираются до начала работы. Второй шаг получает фактический результат первого.
Порядок выбора источников и диагностика инструментов описаны в
[CONVERSION.md](CONVERSION.md).

Fallback применяется только при отсутствии допустимого маршрута в KEPUB.
Сбой запуска или выполнения выбранного маршрута возвращается вызывающему коду;
книга автоматически не отправляется в другом формате после ошибки.
Отсутствие маршрута в совместимый формат возвращает
`ErrorKind::ConversionUnavailable` с диагностикой backend.

## Результат и срок жизни

`prepare_file(book_path, device, options)` сканирует файлы и строит план.
Готовый совместимый файл возвращается без обнаружения/запуска конвертеров.
В режиме `PreferKepub` готового EPUB недостаточно для пропуска обнаружения:
нужно проверить возможность запрошенного преобразования.

`PreparedFile.path` содержит готовый путь, `is_temporary()` указывает на
созданный результат. Объект владеет приватным `Workspace` вне библиотеки:
его необходимо держать живым до окончания копирования или чтения файла.
При освобождении объекта временный каталог удаляется. При ошибке подготовки
явно очищаются промежуточные и частичные файлы; ошибка очистки возвращается
согласно политике этапа №8. Библиотека, OPF и `metadata.db` не меняются.

## Проверки и ограничения

- `cargo test --locked --offline`: 71 тест прошёл, 3 теста верхнего уровня
  игнорируются (реальная конвертация, subprocess-helper, native volume smoke).
  Subprocess-helper запускается отдельным автоматическим тестом.
- Добавлены пять регрессионных тестов: готовые файлы и регистр расширений;
  fallback и ошибка выбранного конвертера; доступные/недоступные маршруты;
  двухшаговая подготовка; сбой на каждом её шаге. Снимки библиотеки проверяют
  неизменность имён и содержимого файлов. Проверена очистка workspace.
- `cargo check --locked --offline`: ядро, TUI и `scan_metadata` прошли.
- `cargo fmt -p rulibre-core -p rulibre -- --check`: прошёл.
- `cargo clippy --locked --offline -p rulibre-core --all-targets`: прошёл
  с прежним предупреждением `collapsible_if` в `metadata.rs`.
- Tauri host: `cargo check --locked --offline -p rulibre-gui` и три теста
  `cargo test --locked --offline -p rulibre-gui` прошли с временными
  `icons/icon.ico` и `dist/index.html`; фикстуры удалены после проверки.

Файловые тесты, rustfmt, Clippy и Tauri выполнялись вне Windows sandbox:
в sandbox блокируются canonicalize/hard links, поиск конфигурации Clippy
и обработка путей Tauri. Для тестов TMP/TEMP направлены в
`target/conversion-tests-temp`.

Матрица форматов остаётся политикой Rulibre из этапов №6/№8; поддержка
отдельных моделей и прошивок физически не подтверждена. EPUB не считается
совместимым USB-файлом Kindle. PDF/TXT не добавлялись в прямую отправку.
Физические ридеры, реальные конвертеры в этом этапе, качество отображения,
Linux/macOS и WASM frontend не проверялись; WASM target отсутствует согласно
исходной матрице. Безопасная публикация реализована в этапе №12:
[SAFE_TRANSFER.md](SAFE_TRANSFER.md). Фоновые задания остаются этапом №13.
Коммит/PR не создан.
